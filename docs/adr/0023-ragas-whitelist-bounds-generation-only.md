# ADR-0023：RAGAS 白名单只约束出题；评估检索镜像生产

- **Status**：Superseded by 0027
- **Date**：2026-10-14
- **Deciders**：用户（决策：评估检索不设白名单，保持整库）；Claude（核实与综合）
- **Supersedes**：ADR-0022 的**决策 C（评估检索与出题同范围）**（局部；ADR-0022 其余决策继续有效，其 `Status` 保持 `Accepted`，正文不作改动）
- **关系**：沿用 ADR-0022 的**决策 A**（出题的输入边界由使用方负责、白名单保留）；证据见 `docs/research/2026-10-13-ragas-testset-generation.md` 与独立架构评审（change `ragas-modern-stack`）。

## 背景与问题

ADR-0022（2026-10-13）定了两条：**A** 保留 `RAGAS_DOC_WHITELIST` 作为**出题**输入边界（使用方职责）；**C** **评估检索与出题同范围**（评估侧也按白名单收窄检索）。

2026-10-14 复核 **决策 C** 时发现其**论证不成立**，且实施代价被低估：

**一、检索由题面驱动，与白名单无关。**
`search(query, kb_id, vector_store)`（`src/rag/retrieval.py:64`）只吃 `query` 与 `kb_id`；检索的 `query` 由被测 Agent 依题面生成（`src/agents/tools/rag_tools.py:147` 调用）。⇒ 题目既然出自白名单文档，**自足题的自然检索即应命中对应文档**，无需额外按白名单过滤。

**二、过滤会掩盖真实信号。**
检索命中白名单**之外**的文档，正是**切块或检索质量的可观测信号**。按白名单过滤会把这类命中**悄悄删掉**——等于把要测的东西藏起来。

**三、过滤让评测测一个生产里不存在的系统。**
生产检索搜**整库**；评测若只搜白名单，则评测对象与生产对象**不是同一个系统**，测出来的分数不可迁移。

**四、过滤可能使 `context_precision` 虚高。**
把本该混进来的、来自其他文档的无关候选**人为删掉**，会抬高 `context_precision`，得出偏乐观的结论。

**五、实施代价被 ADR-0022 低估。**
「评估检索按白名单限定」需要给**共享的生产检索栈**加 doc 级过滤——而 `PgVectorStore.dense_search`（`src/infra/db/vector_store/pg_store.py:144`）与 `lexical_search`（`:179`）**均无 doc 参数**（独立架构评审 F1 核实）。ADR-0022 的 Impact 未申报这些文件。

## 决策

**白名单（`RAGAS_DOC_WHITELIST`）SHALL 仅约束出题的输入文档范围。评估侧检索 SHALL 镜像生产——在被测 Agent 绑定的整个知识库内检索；SHALL NOT 人为按白名单收窄检索范围。**

**证据（本地代码事实）**：

| 事实 | 出处 |
|---|---|
| 检索入口只吃 `query` + `kb_id`，无 doc 过滤 | `src/rag/retrieval.py:64` |
| 检索 `query` 由题面驱动 | `src/agents/tools/rag_tools.py:147` |
| 向量/词法检索均无 doc 参数 | `src/infra/db/vector_store/pg_store.py:144`、`:179` |
| 独立架构评审 F1：检索栈无 doc 过滤 | change `ragas-modern-stack`（2026-10-14） |

**正面**：

- 评测对象与生产对象**一致**（同搜整库），分数可迁移；
- 保留「检索命中意外文档」这一**诊断信号**，不掩盖切块/检索缺陷；
- **不动生产检索代码**（无需给共享检索栈加过滤参数）。

**负面 / 接受的代价**：

- 评测可能命中白名单外文档——**这是刻意保留的**（见「过滤会掩盖真实信号」）；
- 若将来某类评测确需「受控语料上的质量」口径，需另设机制（本 ADR 不提供、也不阻碍）。

## 不解决的问题

- 出题的输入边界仍由使用方负责（ADR-0022 决策 A 继续有效）；
- 白名单绑 `doc_id` 的脆弱性与硬编码位置（ADR-0022 已登记为债），本 ADR 不改。

## 复查触发条件

1. **检索命中外文档被证实是噪声而非信号**（例如外文档长期系统性污染指标、且无法通过其它手段识别）时，重估本条。
2. **需要「受控语料」口径的独立评测**（与生产口径**并列**存在）时，另设机制，而非反转本条。
