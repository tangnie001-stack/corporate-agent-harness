> **归属**：本文件是**机器与网络拓扑的唯一记录**（IP、规格、角色、安全组、证书位置、域名解析）。

> 更新时机：换机、改 DNS、改安全组、证书迁移 —— **当次就改**，否则排障会按旧拓扑找错机器。

## 1. 拓扑

```
公网 ──▶ 入口 ECS (8.133.224.173)        TLS 终结、80→443、反代
            │ 同 VPC 内网 HTTP
            │ 172.30.18.58 ──▶ 172.30.18.59:80
            ▼
        应用 ECS (8.153.17.226)          docker compose：nginx + app + langfuse + pg/redis/minio
```

- **公网只到入口机**：应用机的 80 只对入口机内网 IP 放行，443 不开。
- **证书只在入口机**：应用机不终止 TLS、不需要证书。
- 域名全部解析到入口机；裸域 `tangnie.cn` 也指向它（作用仅是 301 到 www）。
- 切流量的顺序：先配好入口机并用内网 IP 验证 → 再改 DNS（DNS 分钟级生效，有窗口）。

## 5. 证书

- 位置（入口机，系统 nginx）：`/etc/nginx/certs/<域名>/{fullchain.pem,privkey.pem}`
- 覆盖：`www.tangnie.cn` / `api.tangnie.cn` / `langfuse.tangnie.cn`，三张都要，缺一张 nginx 起不来
- 阿里云下载的是 `<域名>.pem` + `<域名>.key`，**上传后必须改名**
- 有效期：2026-10-20 → 2027-01-17（DigiCert DV），续期只需替换文件 + `nginx -s reload`
- 应用机不再需要证书，历史目录 `/opt/www/certs` 可删
